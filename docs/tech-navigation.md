# 網站技術導覽

`/tech/` 顯示技術總覽，可搜尋技術名稱與依來源、類別篩選。點技術名稱或「查看網站」進入 `/tech/?technology=<id>`，頁首直接顯示技術名稱、符合網站數與返回總覽入口；不再把結果放在完整技術排行下方。

- `/tech/?view=sites`：直接瀏覽所有網站，可搜尋名稱或網域、篩選檢查結果。
- 技術結果中的網站名稱連到 `/tech/<domain>/`，顯示版本、偵測依據與檢查紀錄。
- 返回總覽保留來源與類別，清除技術與檢查結果。切換來源即使沒有使用該技術的網站，也保留技術選取並顯示空結果。
- 導覽使用一般連結，支援重新整理、分享網址與瀏覽器上一頁；JavaScript 只負責表格搜尋、排序與分批顯示。
- 資料涵蓋統計移到可展開區塊。技術的網站數與比例仍以所選來源為範圍，比例分母為有成功檢查結果的網站數。

驗證：`npm run typecheck`、Biome、`test/tech-navigation.spec.ts` 與 `test/tech.spec.ts` 共 20 項測試；1280px 桌面與 390px 手機實測技術選取、技術／網站搜尋、詳情、返回、所有網站、空結果與清除篩選。

本次不需資料庫遷移。頁面與樣式在 web 啟動時載入，發布需要重新啟動 web；worker 不需重啟。
