# 同頁截圖核對介面

2026-11-14，使用者指出人工補登結果無法看出資料來自哪張截圖，也再次看到台灣缺值。目標是在原人工補登頁直接對照圖片、辨識值與表單位置，完成核對後才填入。

## 資料與操作

- 桌面使用左右對照：原圖、來源切換與框選在左；概況、國家、全裝置與桌面限定欄位分組在右。兩側各自捲動，分類按鈕可跳到指定欄位並定位原圖，確認與填入操作留在下方。
- 每個欄位顯示來源圖片、可修正的辨識值與原本內容。點欄名或來源按鈕會切換圖片，將辨識框捲入視野；點框也可回到欄位。支援放大與隱藏標記。
- 圖片框依實際 OCR 畫布座標等比例定位。`parseScreenshot(tsv, true)` 產生可選的 `sources` 與 `countryTable`；原有預設呼叫回傳形狀不變。一般欄位標出名稱與數字，圖表渠道則只標對應數字，避免包含左側其他渠道。複核與多圖合併保留來源圖片索引，衝突欄位不留下可誤認為有效結果的來源。
- 國家表存在而台灣缺值時，明示「台灣占比未讀到」，保留空白、未勾選的台灣欄位供補正。其他低信心或衝突欄位也保留待補正位置。國家占比未認出時提供空白列表。任何補正都不由剩餘占比推算。
- 填入前檢查百分比範圍、數字格式、國碼與重複、國家與渠道總和，以及台灣 scalar 與 TW 是否一致。兩個國家欄位皆選取、列表原先缺 TW 時，會依使用者確認的台灣輸入補進列表。核對期間表單若已變動則拒絕覆寫。
- 已有內容預設不勾選。填入只修改原表單並保存既有分頁草稿；保留圖片與核對區，欄位變為唯讀並標示尚未儲存。表單欄位加上來源標記，可回到原圖核對。選擇新圖片或切換月份會移除過期表單來源標記。
- 手機提供上方完整原圖與欄位旁的活動來源局部；欄位清單沿整頁捲動，避免雙重捲動失去對照。沒有水平溢出。說明文字收納進 details，重要範圍與月份提示預設展開；沒有 JavaScript 時保留手填表單。

圖片只使用瀏覽器 Object URL，不上傳或寫入伺服器，也不存進草稿。新選圖會釋放舊 Object URL。樣式放在獨立 `manual-ocr.css`，透過既有 OCR 資源路由釘選內容雜湊，避免影響其他頁面或混入工作區其他樣式修改。

## 驗證與部署

OCR 瀏覽器測試使用暫時 Fastify fixture server，不連正式資料庫或儲存正式補登。涵蓋原圖、重建壓縮圖、實際 Telegram JPG、兩張一起匯入、來源切換與框選、放大、標記切換、手機寬度、舊內容不覆寫、缺值補正、欄位驗證、填入後保留核對與草稿。parser 測試驗證來源座標、有效 scalar 複核與衝突來源排除。

部署只需重啟 web，無 migration 或 worker 重啟。既有補登與人工輸入完全沿用現有儲存路徑。部署檢查與測試結果另存於忽略追蹤的 `data/manual-review-ui-release-*`。
