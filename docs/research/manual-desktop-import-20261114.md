# 外掛截圖：裁切國家表與桌面限定渠道

2026-11-14，使用者提供 s3.com.tw 的 202610 原圖，第二張無法匯入。重現原因是圖片從 `Country` 開始，沒有 `Top 5 Countries`；舊辨識將其下 Traffic Sources 的 Desktop Only 視為整張範圍，因此拒絕整張。

修正後按區塊辨識範圍：上方國家表可只有 Country 標頭，下方 Worldwide／Desktop Only 渠道匯入獨立的桌面限定欄位。全裝置的 Monthly Visits、搜尋／AI 占比與其他渠道不受桌面資料覆寫。未辨識到 Worldwide 或已知裝置範圍的來源仍略過，圖片其他區域若明示桌面／行動限定則不能當作全裝置資料。Mobile Only 渠道目前仍不匯入。

儲存沿用 `manual_months.details` JSON 與既有異動紀錄，不需 migration。`TrafficProfile.desktopChannels` 的鍵名同 `channels`，數值為 0–1；缺值保持未知，明確零保持零。表單使用 `desktop_SearchOrganic`、`desktop_GenAi` 等獨立欄位，月切換、草稿、驗證錯誤保留與重新載入均沿用既有機制。桌面渠道合計不得超過 100.1%（容許四捨五入），單項仍須 0–100%。

網站頁管理員視圖另列「桌面限定流量來源」，只顯示占比，不以全裝置造訪量換算次數；人工補登的 API profile／manualProfiles 保留 desktopChannels，自動估算存在時仍可查看 manualProfiles。匿名與非管理員投影隱藏 desktopChannels，與既有補登明細的權限一致。排行榜、歷史搜尋／AI 數值及月份完整度不把桌面渠道當作全裝置渠道。

本機 Tesseract 也把原圖的美國 2.13% 與聯盟行銷 4.67% 讀成 213%／467%。匯入器現在對低信心或超過 100% 的百分比，從原辨識畫布裁切數字區域再放大兩倍，用單行模式重新辨識；每張最多複核 20 個。只有新的辨識信心至少 80、值在 0–100%、移除小數點後的數字與原辨識相同，且沒有界限符號時才採用。不自行猜測小數點，無法確認仍留空提示核對。所有辨識留在瀏覽器，不使用 AI API 或 token。

實際原圖瀏覽器測試涵蓋：第二張單獨讀入五國 TW 93.23、US 2.13、HK 1.59、ID 0.58、MY 0.57；十個桌面渠道含 SearchOrganic 38.72、SocialPaid 20.48、Direct 13.09、Affiliate 4.67 與 GenAi 0.27，而全裝置搜尋／AI 仍留空。再匯入第一張讀得 482.4K、5.66 頁、00:00:57、71.01%，重新整理保留全部草稿，站外請求被阻擋仍可完成。資料庫整合測試驗證驗證錯誤保留、儲存、重新載入、API、異動紀錄、權限與自動估算優先時的桌面明細，使用測試庫，不代填正式資料。

本次只需重啟 web 載入新 OCR 資源雜湊與表單／呈現；worker 不需重啟，抓取預算與共用退避不變。還原時需保留已存 JSON 的 desktopChannels，避免舊版表單編輯後覆蓋該明細；一般讀取舊資料與空白欄位維持相容。

## 壓縮圖漏認台灣的後續修正

同日使用者回報國家列表缺少台灣。將原國家截圖縮至 65%、以 JPEG 品質 0.8 編碼，重現 PSM 11 仍讀到 93.23%，卻漏掉 Taiwan 名稱；只複核數字無法補回配對。現在國家表不足五國或仍有未配對百分比列時，改以 PSM 6 再讀同張完整畫布，沿用數字裁切複核，只按國碼合併國家資料，其他欄位保留第一輪結果。相同國碼數值衝突則略過該國並提示，合計超過 100.1% 則拒絕國家結果；不從剩餘占比推算台灣。裝置限定的國家表仍不匯入。

原圖、兩張原圖按概況→國家順序匯入、縮小壓縮圖均以真實瀏覽器 OCR 驗證台灣 93.23 同時填入台灣占比及國家列表；新分頁避免草稿掩蓋漏辨識。13 項 OCR 測試通過，typecheck 與 lint 通過。仍使用瀏覽器本機 Tesseract，無 AI API 或 token 成本。
